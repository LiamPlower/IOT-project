#IOT-project

This project uses a ESP-EYE for a camera, a DHT-11 for temperature and humidity readings and a PIR motion sensor with a FS90 servo motor.
When motion is detected, the servo rotates to a specified angle.

## Components
-Arduino
-PIR Motion Sensor
-FS90 Servo Motor
-DHT11
-ESP-EYE

## Functionality
-Detects motion using PIR senso
-Moves servo when motion is deteted
-Detects temperature and humidity using DHT11 sensor
-Captures live footage using ESP-EYE
